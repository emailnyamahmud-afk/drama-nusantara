## Cara Menggunakan

1. **Baca file ringkasan sesuai fase drama yang sedang dikerjakan**:
   - Fase 1-3: Mulai dari `ringkasan-jilid-1-*.md` (prasejarah) → `ringkasan-jilid-2-*.md` (Hindu-Buddha)
   - Fase 4-6: `ringkasan-jilid-3-*.md` (Islamisasi)
   - Fase 7-9: `ringkasan-jilid-4-*.md` (VOC awal, paling lengkap: 40K kata)
   - Fase 10-12: `ringkasan-jilid-5-*.md` (abad kolonial 19)

2. **Cross-reference tokoh**:
   - Setiap file ringkasan punya tabel "Tokoh" dengan tahun, lokasi, sumber primer
   - Cari tokoh lintas-jilid (misal Syekh Yusuf al-Makassari muncul di Jilid 3 & 4 & 5)

3. **Cari "Implikasi untuk Drama"** di akhir setiap bab:
   - Berisi scene suggestion, visual setting, props, tokoh prioritas casting

4. **Audit tersedia**:
   - `audit/audit-jilid3-kemenbud-2025.md` — audit struktural Jilid 3
   - `audit/audit-ringkasan-jilid4.md` — audit cross-check 228 klaim Jilid 4

5. **GitHub**: https://github.com/emailnyamahmud-afk/drama-nusantara
   - Branch: main
   - Path ringkasan: `ringkasan/`
