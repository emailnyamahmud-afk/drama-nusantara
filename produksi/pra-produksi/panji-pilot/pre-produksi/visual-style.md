# Visual Style Guide — Panji: Asmara Bangun

## Pilot 3 Menit

> **Gaya**: Cinematic realistic, inspirasi drama sejarah China (Chinese period drama aesthetic) dengan estetika Nusantara Hindu-Buddha abad 12.

---

## Inspirasi Drama China → Adaptasi Nusantara

| Elemen | Drama China | Adaptasi Nusantara Panji |
|---|---|---|
| **Color palette** | Merah-emas-hitam | Biru-emas (Jenggala) vs Merah-emas (Kediri), dipertemukan di sungai |
| **Set** | Istana China (pilar merah, atap genteng) | Keraton Jenggala & Kediri (pilar batu candi, atap ijuk) |
| **Kostum** | Hanfu / long pao | Kemben-kain-kulit (gaya relief candi Prambanan/Penataran) |
| **Lighting** | Dramatic rim light, backlight | Sama + cahaya api upacara |
| **Camera** | Slow dolly, sweeping wide, shallow DoF close-up | Sama |
| **Texture** | Sutra, brocade | Sutra, batik, gedog, kulit emas |
| **Atmosphere** | Incense smoke, wind-blown curtains | Asap dupa, angin kain tipis, suara gamelan |

## Set Design

> **Filosofi skala**: Kediri/Daha (Dahanapura) dan Jenggala (Kahuripan) bukan kota kecil. Mereka adalah ibukota maritime imperial — setara Angkor Thom atau Konstantinopel di abad 12. Set harus merefleksikan:
> - Kompleks istana multi-bangunan (pendopo, pringgitan, dalem, gadri, pasren, kaputren)
> - Pelabuhan internasional dengan armada perahu dagang (Jung China, perahu Arab, dhows India)
> - Pasar kosmopolitan dengan pedagang multi-etnis
> - Sistem kanal (Brantas navigable ke ibukota)
> - Candi komplek (bukan candi tunggal) — Penataran span 10 km² sebagai referensi

### L001 — Kompleks Keraton Jenggala (Kahuripan)

**Deskripsi**: Kompleks istana Kerajaan Jenggala abad 12 — kota istana di muara Sungai Brantas, dekat pelabuhan Hujung Galuh. Berdasarkan arsitektur Jawa Hindu-Buddha skala imperial:
- **Gerbang utama**: Candi Bentar megah (gerbang belah dua menara) — 8 m tinggi, bata merah
- **Dwarapala** raksasa berlutut di kiri-kanan gerbang (setinggi 3 m)
- **Halaman upacara** luas berbatu andesit (200 m²)
- **Pendopo agung** dengan 16 tiang kayu jati (bukan 8) — merah-emas + emas ukir
- **Atap tumpang sari 3 tingkat** dengan mustaka chandra-kapala
- **Pringgitan** (platform tengah untuk pertunjukan)
- **Dalem** (bilik dalam) dengan tirai beludru
- **Tirai kasa emas** berkibar angin di koridor panjang
- **Obor perunggu** 50+ sepanjang koridor
- **Bendera kerajaan Jenggala** (biru-emas) di menara gerbang
- **Latar belakang**: kota istana dengan candi-candi kecil, kanal air, perahu dagang di kejauhan

**T2I Prompt (Imagen 3 — format 5 komponen Google)**:
```
SUBJECT: Aerial wide establishing shot of Javanese Hindu-Buddhist
imperial palace complex of Jenggala kingdom at Kahuripan, East Java
1100 CE. Multi-building royal court with candi bentar split gate 8m
tall (red brick twin towers), two giant dwarapala guardian statues
3m tall kneeling at gate, large stone ceremonial courtyard 200 sqm,
main pendopo hall with 16 teak pillars blue-gold with gold carvings,
three-tier tumpang sari roof with chandra-kapala (skull-crescent)
finial at peak, pringgitan platform, dalem inner chamber with velvet
curtains, gold mesh curtains blowing in wind along corridors, 50
bronze torches lit, blue-gold royal banner on gate tower.

SETTING: East Java 1100 CE, Brantas river delta. Background shows
canal system with trading boats (jung, perahu), distant small
supporting temples, palm groves, distant mountains (Arjuno, Welirang).
Architecture inspired by Prambanan/Penataran temple relief style.

LIGHTING: Golden hour 3500K warm sunrise from camera left (key
light, long shadows, warm amber glow on stone), soft 6500K sky fill
from above. Mist rising from canals.

MOOD: Megah, tegas, imperial authority — a kingdom that controls
maritime trade and commands respect.

STYLE: Cinematic realistic landscape, Javanese classical aesthetic
inspired by Chinese period drama epics, deep depth of field f/8,
24mm wide lens equivalent, 8K hyperdetailed, photorealistic stone
and wood textures, 35mm film grain, color graded warm amber
highlights cool blue shadows.

Aspect ratio 16:9.

Negative prompt: modern buildings, cars, electric lights, Chinese
pagoda roof, Indian temple, Thai architecture, anime style, cartoon,
3D render, watermark, text, signature, low resolution, blurry,
oversaturated.
```

### L002 — Tepi Sungai Brantas (Perbatasan, Dermaga Imperial)

**Deskripsi**: Tepi Sungai Brantas di fajar — perbatasan alami antara Jenggala di utara dan Kediri di selatan. Bukan pangkalan kayu kecil — dermaga imperial dengan dua sisi (biru-emas utara, merah-emas selatan).
- **Sungai Brantas** lebar (300+ m), mengalir tenang, navigable untuk perahu besar
- **Pohon beringin** tua di tepi
- **Dermaga batu imperial** dua sisi:
  - Dermaga Jenggala (kiri): batu andesit dengan ornamen biru-emas, tiang bendera biru
  - Dermaga Kediri (kanan): batu andesit dengan ornamen merah-emas, tiang bendera merah
- **Perahu kerajaan besar** (bukan perahu kayu kecil) — 20 m panjang, ukiran emas, atap pendopo kecil
- **Armada pengawal** 4-6 perahu per kerajaan, banner masing-masing warna
- **Kabut fajar** di permukaan air
- **Gunung** di latar belakang (Kelud/Kawi/Arjuno)
- **Batu-batu besar** di tepi sungai berukir relief Panji

**T2I Prompt (Imagen 3 — format 5 komponen Google)**:
```
SUBJECT: Wide cinematic establishing shot of Brantas riverbank at
dawn, East Java 1100 CE. Wide river 300m with two imperial stone
docks facing each other across the water: left dock (north, Jenggala)
with blue-gold carved ornaments and tall blue flag pole flying blue-
gold banner, right dock (south, Kediri) with red-gold carved
ornaments and tall red flag pole flying red-gold banner. Each dock
hosts large royal boats 20m long with gold carvings and small
pendopo roofs, fleet of 4-6 escort perahu with respective banners.
Old banyan tree on riverbank, large andesite stones with carved
Panji story reliefs.

SETTING: East Java 1100 CE, Brantas river forming natural border
between Jenggala (north) and Kediri (south). Mountains Kelud, Kawi,
Arjuno in distant background. Tropical dawn mist rising from water.

LIGHTING: Soft warm 3200K dawn light from horizon (key light, golden
orange on water and stones), cool 5500K pre-dawn sky fill from above
(deep blue ambient on shadowed areas). Low contrast ratio 2:1 for
serene morning mood.

MOOD: Sakral, antisipatif, damai — two ancient kingdoms meeting
on neutral ground.

STYLE: Cinematic realistic landscape, Javanese classical aesthetic,
deep depth of field f/8, 24mm wide lens equivalent, 8K hyperdetailed,
photorealistic water reflections and stone textures, 35mm film grain,
color graded warm golden highlights cool blue shadows.

Aspect ratio 16:9.

Negative prompt: modern buildings, modern boats, electric lights,
Chinese architecture, Indian temple, anime style, cartoon, 3D render,
watermark, text, signature, low resolution, blurry, oversaturated.
```

### L003 — Kompleks Candi Upacara (Bukan Candi Tunggal)

**Deskripsi**: Kompleks candi besar untuk upacara pernikahan Panji-Candra Kirana — bukan satu candi kecil, tapi kumpulan candi (refleksi Candi Penataran yang membentang 10 km²).
- **Candi utama** (3 tingkat, 15 m tinggi) dengan relief Panji di dinding
- **Candi-candi kecil** di sekeliling (6-8 candi pendukung)
- **Halaman batu** luas (50 m²)
- **Altar api suci** (homa yajna) — 2 m tinggi, perunggu berukir
- **Bunga teratai** dan melati di sekitar, karpet bunga
- **Karpet kain emas** dari altar ke singgasana — 20 m panjang
- **Obor perunggu** besar di 8 penjuru
- **Bintang/malam** di langit
- **Tiang-tiang panji** dengan banner dua kerajaan
- **Patung dewa-dewi** (Kama Jaya-Kamaratih) di gerbang

**T2I Prompt (Imagen 3 — format 5 komponen Google)**:
```
SUBJECT: Wide cinematic shot of Javanese Hindu-Buddhist temple
complex courtyard at night, East Java 1100 CE. Multi-temple complex
with main 3-tier candi 15m tall featuring Panji story reliefs on
walls (visible carvings of Panji Asmara Bangun and Candra Kirana),
6-8 smaller supporting candi around, large stone courtyard 50 sqm,
sacred fire altar (homa yajna) 2m tall bronze carved at center,
lotus and jasmine flowers lining paths, golden carpet 20m from
altar to throne, 8 large bronze torches blazing at corners, flag
poles with two kingdom banners (blue-gold Jenggala left and red-
gold Kediri right), statues of Kamajaya-Kamaratih at gateway.

SETTING: East Java 1100 CE, Javanese Hindu-Buddhist temple complex
(inspired by Penataran complex which spans 10 sq km). Architecture
in Prambanan/Penataran relief style. Starry tropical night sky with
faint Milky Way visible.

LIGHTING: Intense warm 2200K sacred firelight from altar at center
(key light, dramatic orange glow on surrounding stone and faces),
soft 4500K torch fill from 8 perimeter torches, deep blue 5500K
moonlight from above. Sparks rising from sacred fire floating
upward. High contrast 4:1 for sacred dramatic chiaroscuro.

MOOD: Sakral, megah, emosional — celestial union of two kingdoms
witnessed by gods.

STYLE: Cinematic realistic landscape, Javanese classical aesthetic
inspired by Chinese period drama, deep depth of field f/5.6, 35mm
lens equivalent, 8K hyperdetailed, photorealistic fire and stone
textures, 35mm film grain, color graded warm fire-orange highlights
cool blue-black shadows.

Aspect ratio 16:9.

Negative prompt: modern buildings, electric lights, Chinese temple,
Indian temple, Thai chedi, anime style, cartoon, 3D render,
watermark, text, signature, low resolution, blurry, oversaturated.
```

### L004 — Pelabuhan Hujung Galuh (Pelabuhan Imperial Jenggala)

**Deskripsi**: Pelabuhan maritime imperial Kerajaan Jenggala di muara Sungai Brantas (modern Surabaya/Sidoarjo). Pusat dagang Asia Tenggara abad 12.
- **Dermaga panjang** batu 200+ m
- **Jung China** besar (40+ m) bersandar
- **Perahu Arab/India** (dhows) berlayar
- **Perahu Jawa** khas (jong, pelang) — 20-30 m
- **Gudang dagang** bata merah di tepi
- **Pasar kosmopolitan** — pedagang Tionghoa, Tamil, Arab, Jawa, Melayu
- **Tiang bendera** biru-emas di gerbang pelabuhan
- **Menara pengawas** kayu setinggi 10 m
- **Pabean** (custom house) dengan patih pelabuhan
- **Laut Madura** di latar belakang

## Costume Detail

### Kostum Pangeran Jenggala (C001 — Panji Asmara Bangun)

```
Layer 1 (dalam): Kain putih tipis (inner robe)
Layer 2 (tengah): Tunic biru tua dengan bordir emas
  - Motif: kala-makara di dada
  - Motif: daun-daunan di bahu
  - Warna: biru tua (#1A237E) + emas (#D4AF37)
Layer 3 (luar): Kain batik biru tua-emas (di pinggang ke bawah)
  - Corak: parang rusak
  - Warna: biru tua (#1A237E) + emas (#D4AF37)
Aksesori:
  - Destar/ikat kepala biru-emas (atau panji-cap khas pangeran Jenggala)
  - Kalung emas sederhana
  - Keris pusaka (gagang emas-kayu, sarung kayu)
  - Gelang kairo emas (lengan atas dan pergelangan)
  - Anting-anting emas kecil (opsional, gaya Jawa Kuno)
```

### Kostum Putri Kediri (C002 — Candra Kirana/Sekartaji)

```
Layer 1 (dalam): Kain putih tipis
Layer 2 (atas): Kemben emas-brocade
  - Motif: teratai (lotus)
  - Warna: emas (#D4AF37) + putih gading
Layer 3 (bawah): Kain batik merah tua-emas
  - Corak: parang klawu
  - Warna: merah tua (#8B0000) + emas (#D4AF37)
Aksesori:
  - Mahkota emas kecil dengan hiasan bunga melati
  - Kalung emas dengan liontin teratai (lotus)
  - Gelang kairo emas (pergelangan tangan dan kaki)
  - Anting-anting emas
  - Cincin emas
```

### Kostum Patih (C003)

```
Layer 1: Kain cokelat (kain jedor)
Layer 2: Kulit hitam (leather vest, tanpa ornamen emas)
Aksesori: Blangkon/cloth head wrap, sandal jepit kayu
```

### Kostum Mpu Dharmaja (C004)

```
Layer 1: Jubah putih-kuning (Siwa priest robe)
Layer 2: Selendang emas-tipis di bahu
Aksesori: Tasbih batu, sanggul rambut, lontar (palm leaf manuscript)
```

## Pipeline T2I Workflow

```
Step 1: Generate 4 character refs (C001-C004)
  → Save to refs/C00X_base.png

Step 2: Generate 5 location refs (L001-L005)
  → L001 Kompleks Keraton Jenggala (Kahuripan)
  → L002 Tepi Sungai Brantas (Dermaga Imperial)
  → L003 Kompleks Candi Upacara
  → L004 Pelabuhan Hujung Galuh (Pelabuhan Imperial)
  → L005 Kota Imperial Dahanapura (Ibukota Kediri)
  → Save to refs/L00X_base.png

Step 3: Generate 36 segmen images
  → Each prompt includes character + location ref
  → Save to segments/SXX_segYY/image.png

Step 4: Generate 36 audio clips
  → Narator (TTS) + dialog (TTS) + ambient (SFX library)
  → Save to segments/SXX_segYY/audio.wav

Step 5: Generate 36 video clips (I2V)
  → Image → 5 second video
  → Save to segments/SXX_segYY/video.mp4

Step 6: Assembly
  → Concat 36 segmen → 3 scenes → 1 episode
  → Add transitions + BGM + color grading
  → Output: episode_01_panji_pilot.mp4
```
