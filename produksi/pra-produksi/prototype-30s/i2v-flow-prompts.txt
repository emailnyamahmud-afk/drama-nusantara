Settings di Google Flow (sama untuk semua segmen):
  - Resolution: 360p
  - Duration: 4s (4 detik — pilihan terdekat dengan target 5s)
  - Estimasi credits per video: 4cr
  - Total 6 video: 24cr (sisa 26cr untuk iterate)
  - Audio native: YA (SFX included)
  - Watermark: TIDAK ADA

Workflow per segmen:
  1. Buka https://flow.google.com
  2. Upload image dari produksi/t2i-output/prototype-30s/{segment_id}.jpg
  3. Copy-paste motion prompt di bawah
  4. Set Resolution = 360p, Duration = 4s
  5. Generate → download .mp4
  6. Save ke: produksi/i2v-output/prototype-30s/flow-{segment_id}.mp4

Note: durasi 4s vs target 5s = -1s per video. Total video 24s bukan 30s.
Solusi: pakai slow-motion di ffmpeg untuk extend ke 30s, atau trim TTS narasi jadi 24s.
