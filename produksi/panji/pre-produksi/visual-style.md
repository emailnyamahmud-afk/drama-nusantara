# Visual Style Guide — Panji: Asmara Bangun

## Pilot 3 Menit

> **Gaya**: Cinematic realistic, inspirasi drama sejarah China (Chinese period drama aesthetic) dengan estetika Nusantara Hindu-Buddha abad 12.

---

## Inspirasi Drama China → Adaptasi Nusantara

| Elemen | Drama China | Adaptasi Nusantara Panji |
|---|---|---|
| **Color palette** | Merah-emas-hitam | Emas-merah tua-cokelat gelap (warna keraton Jawa) |
| **Set** | Istana China (pilar merah, atap genteng) | Keraton Kediri (pilar batu candi, atap ijuk) |
| **Kostum** | Hanfu / long pao | Kemben-kain-kulit (gaya relief candi Prambanan/Borobudur) |
| **Lighting** | Dramatic rim light, backlight | Sama + cahaya api upacara |
| **Camera** | Slow dolly, sweeping wide, shallow DoF close-up | Sama |
| **Texture** | Sutra, brocade | Sutra, batik, gedog, kulit emas |
| **Atmosphere** | Incense smoke, wind-blown curtains | Asap dupa, angin kain tipis, suara gamelan |

## Set Design

### L001 — Keraton Kediri (Dahanapura)

**Deskripsi**: Istana kerajaan Kediri abad 12. Berdasarkan arsitektur Jawa Hindu-Buddha:
- **Pilar batu candi** (mirip Candi Penataran/Kediri)
- **Atap ijuk** (merang / aren palm)
- **Lantai batu** (andesit)
- **Ornamen** motif kala-makara, daun-daunan, lotus
- **Tirai kain tipis** (kasa emas) berkibar angin
- **Obor** di sepanjang koridor
- **Bendera kerajaan** (merah-emas) di atas

**T2I Prompt**:
```
Javanese Hindu palace interior, 12th century Kediri kingdom, stone
pillars with kala-makara ornaments, palm fiber roof, andesite floor,
gold silk curtains blowing in wind, torches along corridor, red-gold
royal banner above, cinematic, dramatic lighting, 8K, hyperdetailed
```

### L002 — Tepi Sungai Brantas (Perbatasan)

**Deskripsi**: Tepi Sungai Brantas di fajar — perbatasan alami antara Kediri dan Jenggala.
- **Sungai besar** mengalir tenang
- **Pohon beringin** tua di tepi
- **Pangkalan kayu** kecil (dermaga perahu kerajaan)
- **Kabut fajar** di permukaan air
- **Gunung** di latar belakang (Kelud/Kawi)
- **Batu-batu besar** di tepi sungai

**T2I Prompt**:
```
Brantas riverbank at dawn, 12th century East Java, misty river
surface, old banyan tree, small wooden royal pier, mountains in
background, golden sunrise light, serene, cinematic wide shot, 8K,
hyperdetailed
```

### L003 — Candi / Altar Upacara

**Deskripsi**: Halaman candi untuk upacara pernikahan.
- **Candi batu** kecil (mirip candi di Kediri/Tulungagung)
- **Altar api suci** (homa yajna)
- **Bunga teratai** dan melati di sekitar
- **Karpet kain emas** dari altar ke singgasana
- **Obor** di empat penjuru
- **Bintang/malam** di langit

**T2I Prompt**:
```
Javanese Hindu temple courtyard at night, 12th century, sacred fire
altar, stone candi, lotus and jasmine flowers, golden carpet from
altar to throne, four torches at corners, starry night sky, warm
firelight, cinematic, 8K, hyperdetailed
```

## Costume Detail

### Kostum Kerajaan Kediri (C001 — Kameswara)

```
Layer 1 (dalam): Kain putih tipis (inner robe)
Layer 2 (tengah): Kulit emas dengan ukiran motif candi
  - Motif: kala-makara di dada
  - Motif: daun-daunan di bahu
  - Warna: emas (#D4AF37)
Layer 3 (luar): Kain batik merah tua-emas (di pinggang ke bawah)
  - Corak: parang rusak
  - Warna: merah tua (#8B0000) + emas (#D4AF37)
Aksesori:
  - Mahkota emas (makuta) dengan puncak Siwa lingga
  - Kalung emas dengan liontin lingga-yoni
  - Gelang kairo emas (lengan atas dan pergelangan)
  - Keris pusaka (gagang emas, sarung kayu)
  - Anting-anting emas kecil
```

### Kostum Putri Jenggala (C002 — Sri Kirana)

```
Layer 1 (dalam): Kain putih tipis
Layer 2 (atas): Kemben emas-brocade
  - Motif: teratai (lotus)
  - Warna: emas (#D4AF37) + putih gading
Layer 3 (bawah): Kain batik biru tua-emas
  - Corak: parang klawu
  - Warna: biru tua (#1A237E) + emas (#D4AF37)
Aksesori:
  - Mahkota emas kecil dengan hiasan bunga melati
  - Kalung emas dengan liontin teratai
  - Gelang kairo emas (pergelangan tangan dan kaki)
  - Anting-anting emas
  - Cincin emas
```

### Kostum Patih (C003)

```
Layer 1: Kain cokelat (kain jedor)
Layer 2: Kulit hitam (leather vest, tanpa ornamen emas)
Aksesori: Blangkon/cloth head wrap, sandal jepit kayu
```

### Kostum Mpu Dharmaja (C004)

```
Layer 1: Jubah putih-kuning (Siwa priest robe)
Layer 2: Selendang emas-tipis di bahu
Aksesori: Tasbih batu, sanggul rambut, lontar (palm leaf manuscript)
```

## Camera & Composition

### Shot Types (Drama China Style)

| Shot | Penggunaan | Segmen |
|---|---|---|
| **Extreme wide shot** | Establishing — keraton, sungai | 01, 13, 25 |
| **Wide shot** | Group — Kameswara + patih, upacara | 05, 09, 27 |
| **Medium shot** | Dialog — Kameswara & Kirana | 17, 19, 21 |
| **Close-up** | Emosi — wajah Kameswara, Kirana | 18, 22, 31 |
| **Extreme close-up** | Detail — keris, tangan, mata | 03, 20, 30 |
| **Over-the-shoulder** | Dialog — POV Kameswara ke Kirana | 23 |
| **Low angle** | Power — Kameswara di singgasana | 07 |
| **High angle** | Vulnerability — Kirana dari kapal | 14 |
| **Slow dolly** | Reveal — dari obor ke Kameswara | 06 |
| **Static** | Upacara — formal, simetris | 26, 28 |

### Aspect Ratio & Quality

```
Aspect: 16:9 (1920x1080)
FPS: 24
Color: sRGB
Bit depth: 8-bit (pilot), 10-bit (production)
```

## Pipeline T2I Workflow

```
Step 1: Generate 4 character refs (C001-C004)
  → Save to refs/C00X_base.png

Step 2: Generate 3 location refs (L001-L003)
  → Save to refs/L00X_base.png

Step 3: Generate 36 segmen images
  → Each prompt includes character + location ref
  → Save to segments/SXX_segYY/image.png

Step 4: Generate 36 audio clips
  → Narator (TTS) + dialog (TTS) + ambient (SFX library)
  → Save to segments/SXX_segYY/audio.wav

Step 5: Generate 36 video clips (I2V)
  → Image → 5 second video
  → Save to segments/SXX_segYY/video.mp4

Step 6: Assembly
  → Concat 36 segmen → 3 scenes → 1 episode
  → Add transitions + BGM + color grading
  → Output: episode_01_panji_pilot.mp4
```
