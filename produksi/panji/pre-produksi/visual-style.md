# Visual Style Guide — Panji: Asmara Bangun

## Pilot 3 Menit

> **Gaya**: Cinematic realistic, inspirasi drama sejarah China (Chinese period drama aesthetic) dengan estetika Nusantara Hindu-Buddha abad 12.

---

## Inspirasi Drama China → Adaptasi Nusantara

| Elemen | Drama China | Adaptasi Nusantara Panji |
|---|---|---|
| **Color palette** | Merah-emas-hitam | Biru-emas (Jenggala) vs Merah-emas (Kediri), dipertemukan di sungai |
| **Set** | Istana China (pilar merah, atap genteng) | Keraton Jenggala & Kediri (pilar batu candi, atap ijuk) |
| **Kostum** | Hanfu / long pao | Kemben-kain-kulit (gaya relief candi Prambanan/Penataran) |
| **Lighting** | Dramatic rim light, backlight | Sama + cahaya api upacara |
| **Camera** | Slow dolly, sweeping wide, shallow DoF close-up | Sama |
| **Texture** | Sutra, brocade | Sutra, batik, gedog, kulit emas |
| **Atmosphere** | Incense smoke, wind-blown curtains | Asap dupa, angin kain tipis, suara gamelan |

## Color Palette per Babak

### Babak 1 — "Dua Kerajaan, Satu Sungai" (Jenggala)

```
Primary:   #1A237E (biru tua — Jenggala, bendera, kostum Panji)
Secondary: #D4AF37 (emas — mahkota, ornamen)
Accent:    #3E2723 (cokelat gelap — kayu, batu)
Background:#0D1117 (hitam kebiruan — interior keraton malam)
Light:     #FFE082 (kuning lembut — obor, matahari terbit)
```

**Mood**: Tegas, kuat, sedikit menekan. Panji Asmoro Bangun adalah pangeran yang berkuasa dan berwibawa.

### Babak 2 — "Pertemuan di Brantas" (Perbatasan)

```
Primary:   #1A237E (biru tua — fajar, sungai, Jenggala)
Secondary: #8B0000 (merah tua — Kediri, kirana)
Accent:    #E8F5E9 (hijau muda — alam, tanaman)
Background:#0D1117 (gelap — sebelum fajar)
Light:     #FFE082 (kuning lembut — matahari terbit)
```

**Mood**: Misterius, penasaran, transisi dari gelap ke terang. Pertemuan dua warna kerajaan (biru Jenggala vs merah Kediri) yang akhirnya berdamai.

### Babak 3 — "Smaradahana" (Upacara)

```
Primary:   #FFD700 (emas — api suci, kemegahan)
Secondary: #FF6F00 (oranye — api, semangat)
Accent:    #FAFAFA (putih — kesucian, kain upacara)
Background:#1A0F0A (gelap — malam, upacara sakral)
Light:     #FF8F00 (oranye hangat — api upacara)
```

**Mood**: Sakral, megah, emosional. Puncak cerita. Dua kerajaan bersatu dalam api Smaradahana.

## Set Design

### L001 — Keraton Jenggala (Kahuripan)

**Deskripsi**: Istana kerajaan Jenggala abad 12. Berdasarkan arsitektur Jawa Hindu-Buddha:
- **Pilar batu candi** (mirip Candi Penataran/Kediri)
- **Atap ijuk** (merang / aren palm)
- **Lantai batu** (andesit)
- **Ornamen** motif kala-makara, daun-daunan, lotus
- **Tirai kain tipis** (kasa emas) berkibar angin
- **Obor** di sepanjang koridor
- **Bendera kerajaan Jenggala** (biru-emas) di atas

**T2I Prompt**:
```
Javanese Hindu palace interior, 12th century Jenggala kingdom, blue-gold
royal theme, stone pillars with kala-makara ornaments, palm fiber roof,
andesite floor, gold silk curtains blowing in wind, torches along
corridor, blue-gold royal banner above, cinematic, dramatic lighting, 8K,
hyperdetailed
```

### L002 — Tepi Sungai Brantas (Perbatasan)

**Deskripsi**: Tepi Sungai Brantas di fajar — perbatasan alami antara Jenggala di utara dan Kediri di selatan.
- **Sungai besar** mengalir tenang
- **Pohon beringin** tua di tepi
- **Pangkalan kayu** kecil (dermaga perahu kerajaan, dua sisi — biru utara, merah selatan)
- **Kabut fajar** di permukaan air
- **Gunung** di latar belakang (Kelud/Kawi)
- **Batu-batu besar** di tepi sungai

**T2I Prompt**:
```
Brantas riverbank at dawn, 12th century East Java, misty river surface,
old banyan tree, two wooden royal piers (one blue-gold Jenggala side,
one red-gold Kediri side), mountains in background, golden sunrise
light, serene, cinematic wide shot, 8K, hyperdetailed
```

### L003 — Candi / Altar Upacara

**Deskripsi**: Halaman candi untuk upacara pernikahan Panji-Candra Kirana.
- **Candi batu** kecil (mirip candi di Kediri/Tulungagung)
- **Altar api suci** (homa yajna)
- **Bunga teratai** dan melati di sekitar
- **Karpet kain emas** dari altar ke singgasana
- **Obor** di empat penjuru
- **Bintang/malam** di langit

**T2I Prompt**:
```
Javanese Hindu temple courtyard at night, 12th century, sacred fire
altar, stone candi, lotus and jasmine flowers, golden carpet from
altar to throne, four torches at corners, starry night sky, warm
firelight, cinematic, 8K, hyperdetailed
```

## Costume Detail

### Kostum Pangeran Jenggala (C001 — Panji Asmoro Bangun)

```
Layer 1 (dalam): Kain putih tipis (inner robe)
Layer 2 (tengah): Tunic biru tua dengan bordir emas
  - Motif: kala-makara di dada
  - Motif: daun-daunan di bahu
  - Warna: biru tua (#1A237E) + emas (#D4AF37)
Layer 3 (luar): Kain batik biru tua-emas (di pinggang ke bawah)
  - Corak: parang rusak
  - Warna: biru tua (#1A237E) + emas (#D4AF37)
Aksesori:
  - Destar/ikat kepala biru-emas (atau panji-cap khas pangeran Jenggala)
  - Kalung emas sederhana
  - Keris pusaka (gagang emas-kayu, sarung kayu)
  - Gelang kairo emas (lengan atas dan pergelangan)
  - Anting-anting emas kecil (opsional, gaya Jawa Kuno)
```

### Kostum Putri Kediri (C002 — Candra Kirana/Sekartaji)

```
Layer 1 (dalam): Kain putih tipis
Layer 2 (atas): Kemben emas-brocade
  - Motif: teratai (lotus)
  - Warna: emas (#D4AF37) + putih gading
Layer 3 (bawah): Kain batik merah tua-emas
  - Corak: parang klawu
  - Warna: merah tua (#8B0000) + emas (#D4AF37)
Aksesori:
  - Mahkota emas kecil dengan hiasan bunga melati
  - Kalung emas dengan liontin teratai (lotus)
  - Gelang kairo emas (pergelangan tangan dan kaki)
  - Anting-anting emas
  - Cincin emas
```

### Kostum Patih (C003)

```
Layer 1: Kain cokelat (kain jedor)
Layer 2: Kulit hitam (leather vest, tanpa ornamen emas)
Aksesori: Blangkon/cloth head wrap, sandal jepit kayu
```

### Kostum Mpu Dharmaja (C004)

```
Layer 1: Jubah putih-kuning (Siwa priest robe)
Layer 2: Selendang emas-tipis di bahu
Aksesori: Tasbih batu, sanggul rambut, lontar (palm leaf manuscript)
```

### Pewarnaan Khas Dua Kerajaan (Untuk Figuran & Detail)

| Kerajaan | Warna utama | Warna sekunder | Bendera |
|----------|-------------|----------------|---------|
| **Jenggala** (utara, Panji) | Biru tua (#1A237E) | Emas (#D4AF37) | Biru-emas |
| **Kediri/Daha** (selatan, Candra Kirana) | Merah tua (#8B0000) | Emas (#D4AF37) | Merah-emas |

Kedua kerajaan berbagi emas sebagai warna kemewahan, dibedakan oleh warna primer (biru vs merah). Saat upacara pernikahan, dua warna ini bersatu.

## Camera & Composition

### Shot Types (Drama China Style)

| Shot | Penggunaan | Segmen |
|---|---|---|
| **Extreme wide shot** | Establishing — sungai, dua keraton | 01, 13, 25 |
| **Wide shot** | Group — Panji + patih, upacara | 05, 09, 27 |
| **Medium shot** | Dialog — Panji & Candra Kirana | 17, 19, 21 |
| **Close-up** | Emosi — wajah Panji, Candra Kirana | 18, 22, 31 |
| **Extreme close-up** | Detail — keris, tangan, mata | 03, 20, 30 |
| **Over-the-shoulder** | Dialog — POV Panji ke Candra Kirana | 23 |
| **Low angle** | Power — Panji di singgasana | 07 |
| **High angle** | Vulnerability — Candra Kirana dari kapal | 14 |
| **Slow dolly** | Reveal — dari obor ke Panji | 06 |
| **Static** | Upacara — formal, simetris | 26, 28 |

### Aspect Ratio & Quality

```
Aspect: 16:9 (1920x1080)
FPS: 24
Color: sRGB
Bit depth: 8-bit (pilot), 10-bit (production)
```

## Pipeline T2I Workflow

```
Step 1: Generate 4 character refs (C001-C004)
  → Save to refs/C00X_base.png

Step 2: Generate 3 location refs (L001-L003)
  → Save to refs/L00X_base.png

Step 3: Generate 36 segmen images
  → Each prompt includes character + location ref
  → Save to segments/SXX_segYY/image.png

Step 4: Generate 36 audio clips
  → Narator (TTS) + dialog (TTS) + ambient (SFX library)
  → Save to segments/SXX_segYY/audio.wav

Step 5: Generate 36 video clips (I2V)
  → Image → 5 second video
  → Save to segments/SXX_segYY/video.mp4

Step 6: Assembly
  → Concat 36 segmen → 3 scenes → 1 episode
  → Add transitions + BGM + color grading
  → Output: episode_01_panji_pilot.mp4
```
