# TEMPLATE — Master Era

> **Template ini wajib dipakai untuk semua dokumen era berikutnya** (1B, 1C, 1D, dst).
> **Filosofi**: Dokumen era = riset & bahan-bahan aset berdasarkan sumber primer. BUKAN naskah produksi (drama/dokumenter). Output format akan dipilih di fase berikutnya.

## Aturan Penulisan

1. **Setiap klaim harus punya sitasi sumber primer** — file + section + halaman buku asli. Tidak boleh ada klaim tanpa sumber.
2. **Tidak ada improvisasi psikologis** (karakterisasi drama, mood scene, palette warna) — itu fase produksi, bukan master era.
3. **Tidak ada "scene potensial"** — itu fase storyboard, bukan master era.
4. **Aset visual = bahan** (profil referensi, properti historis, latar historis) — bukan instruksi produksi.
5. **Inferensi negatif** (yang tidak ada buktinya) wajib ditandai: "Tidak ada bukti — inferensi negatif".

## Struktur Wajib (8 Bagian)

```
# MASTER ERA <KODE> — <Nama Era> (<Periode>)

> Periode
> Sub-era (1A/1B/1C/1D)
> Sumber primer utama (file + halaman)
> Status: Master era
> Tanggal

# BAGIAN 1 — KONTEKS ERA
1.1 Batas periode
1.2 Kerangka geografi
1.3 Kerangka iklim & vegetasi
1.4 Kerangka geologi/politik/sosial (sesuai era)

# BAGIAN 2 — NARASI KRONOLOGI (Berdasar Sumber Primer)
2.1 Akt 1 — <peristiwa 1>
2.2 Akt 2 — <peristiwa 2>
...

# BAGIAN 3 — TOKOH (Profil Historis Berdasar Fosil/Prasasti/Naskah)
3.1 Tokoh 1 — <nama>
  3.1.1 Identifikasi (nama ilmiah/gelar, periode, sumber)
  3.1.2 Profil fisik (tinggi, wajah, atribut — dengan sumber primer)
  3.1.3 Budaya material (kostum, properti, alat — dengan sumber primer)
  3.1.4 Konteks historis (peran, signifikansi)
3.2 Tokoh 2 — dst.

# BAGIAN 4 — LATAR (Geografi & Lingkungan Historis)
4.1 Latar 1 — <nama>
  4.1.1 Geografi historis
  4.1.2 Arsitektur/stratigrafi/konfigurasi
  4.1.3 Vegetasi/fauna (jika relevan)
4.2 Latar 2 — dst.

# BAGIAN 5 — SUMBER PRIMER YANG DIPAKAI
5.1 Kutipan langsung (tabel: klaim → file → section → halaman)
5.2 Referensi sekunder yang disitir di sumber primer

# BAGIAN 6 — ASET VISUAL (Bahan untuk Fase Produksi Berikutnya)
6.1 Aset tokoh — profil referensi
6.2 Aset latar — elemen latar
6.3 Aset properti — daftar benda historis
6.4 Aset fauna/flora — daftar
6.5 Aset geologi/arsitektur — daftar

# BAGIAN 7 — STATISTIK DOKUMEN
- Total kata
- Sumber primer dipakai
- Klaim dengan sitasi
- Tokoh utama/pendukung/konteks
- Latar utama
- Aset visual
- Status: berdasar sumber primer / tanpa halu

# BAGIAN 8 — TRANSISI KE ERA BERIKUTNYA
- Era berikutnya: <kode + nama + periode>
- Yang akan dibahas
- Sumber primer yang akan dipakai
```
