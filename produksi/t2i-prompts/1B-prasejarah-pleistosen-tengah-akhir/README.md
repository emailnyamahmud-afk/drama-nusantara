### Iterasi Multi-Turn Khusus 1B

- **Homo erectus soloensis (1B-K001)**: "Make him look more like the last of his kind — deeper wrinkles, weathered, tired but wise"
- **Homo floresiensis (1B-K002)**: "She should look adult but very short (106 cm) — emphasize dwarf proportions, not child-like"
- **Manusia Wajak (1B-K003)**: "He is early Homo sapiens, not Homo erectus — give him modern features (vertical forehead, chin) but keep Australoid characteristics"
- **MMAA Lida Ajer (1B-K004)**: "She is fully Homo sapiens — modern features, but rainforest adaptation, not savanna-adapted"
- **Toba (1B-L001)**: "Make the eruption more apocalyptic — bigger mushroom cloud, more lightning, more devastation"

### Quality Gate Khusus 1B

- [ ] Homo erectus soloensis: brow ridge slightly reduced vs 1A Homo erectus (evolusi progresif)
- [ ] Homo floresiensis: 106 cm tall (dwarf), adult face, NOT child
- [ ] Manusia Wajak: Homo sapiens features (vertical forehead, chin)
- [ ] MMAA Lida Ajer: fully modern Homo sapiens (thin brow ridge, vertical forehead, chin)
- [ ] Toba eruption: apocalyptic scale, 40+ km eruption column, volcanic lightning
- [ ] Liang Bua: cave interior, NOT open landscape
- [ ] Stegodon: downward-curving tusks (NOT modern elephant straight tusks)
