## Catatan Penggunaan

### Workflow Google Flow (flow.google.com)

1. Buka https://flow.google.com → login Google account
2. Create new project → pilih model "Nano Banana 2.1"
3. Set aspect ratio sesuai tabel di atas (9:16 untuk karakter ref, 16:9 untuk cinematic, 1:1 untuk macro)
4. Set resolution: 2K (cukup untuk pilot) atau 4K (production)
5. Copy seluruh isi prompt (mulai dari "SUBJECT:" sampai sebelum "Aspect ratio")
6. Paste ke chat box Flow
7. Generate → review → iterate via multi-turn chat (jangan generate ulang)
8. Quality gate (lihat prompt-engineering-guide.md section F)
9. Download → simpan ke:
   - `produksi/t2i-prompts/1A-prasejarah-pleistosen-awal/refs/1A-K001_homo_erectus.png` dst

### Iterasi Multi-Turn

Jika hasil pertama belum pas, jangan klik Generate ulang. Gunakan chat:
- "Make the lighting more dramatic, increase contrast to 6:1"
- "The face looks too modern, increase brow ridge thickness and reduce forehead height"
- "The skin is too clean, add dirt, sweat, and weathering"
- "Background too generic, add more Pleistocene fauna in distance"

### Quality Gate

Sebelum lock ref image, cek:
- [ ] Wajah/wajah terlihat Homo erectus (bukan Homo sapiens, Neanderthal, atau modern)
- [ ] Tidak ada pakaian/perhiasan (Pleistosen Awal = no evidence of clothing)
- [ ] Background period-akurat (savana, no modern vegetation)
- [ ] Fauna pleistosen (Stegodon, bukan modern elephant)
- [ ] Tidak ada elemen modern (kabel, bangunan, dll)
- [ ] Detail tekstur cukup (kulit dengan pori-pori, batu dengan mineral)
- [ ] Aspek rasio sesuai target
